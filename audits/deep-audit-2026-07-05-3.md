## Runtime Regression Found and Fixed

The first 10.0.0 artifact failed during mixin preparation because optional mixin detection used `Class.forName(..., false, ...)`. Defining an optional target can also define its Minecraft supertypes, which loaded `BlockBehaviour` before KubeJS prepared `BlockBehaviourMixin`.

Optional target detection now checks `.class` resources without defining classes. An automated sentinel test verifies that discovery does not initialize the target. The final dedicated-server run did not reproduce `MixinTargetAlreadyLoadedException`.

Legacy island data also contained `minecraft:Unknown`. The loader now treats both `Unknown` and namespaced `Unknown` values as the unset biome sentinel. The final run produced no invalid-biome warning.
