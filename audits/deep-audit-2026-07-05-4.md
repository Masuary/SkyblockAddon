# SkyblockAddon Terralith Safety Verification - 2026-07-05

## Verdict: YELLOW

The mandatory Terralith incompatibility guard is restored. SkyblockAddon now throws `TerralithFoundException` during Forge inter-mod processing when mod ID `terralith` is present. This lifecycle phase occurs before the dedicated server opens a world, preventing incompatible terrain generation from replacing the required void overworld.

The overall release remains yellow because the broader production migration comparison and interaction matrix are still incomplete.

## Required Invariant

Do not replace the Terralith failure with a warning or optional compatibility path. SkyblockAddon requires a void overworld, and a server with Terralith installed must not proceed to world loading.
